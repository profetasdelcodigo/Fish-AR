# Fish AR · Piura 3D fish assets

These encounter meshes are kept locally in the Android APK so Fish AR does not depend on an external model server.

Primary Piura food-fish set:

- `caballa.obj` — Scomber japonicus
- `cachema.obj` — Cynoscion analis
- `jurel.obj` — Trachurus murphyi
- `cabrilla.obj` — Paralabrax humeralis
- `camotillo.obj` — Diplectrum eumelum

Each mesh has its own MTL material. The visual encounter renderer keeps the existing high-detail fish renders for photorealistic presentation while the mesh manifest provides the native 3D asset set for spatial/AR integration.

The species selection is grounded in Piura consumption research identifying caballa, cachema, jurel, cabrilla and camotillo among the most consumed fish in the city of Piura.
